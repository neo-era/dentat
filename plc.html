🔢 Đọc / ghi biến số (VW, VD)

Setpoint timer, counter, ngưỡng analog… Giá trị "Hiện tại" cập nhật theo chu kỳ polling.

📈 Biểu đồ thời gian thực

Lưu 0 mẫu. Mỗi mẫu = 1 chu kỳ polling. Dữ liệu chỉ lưu trong session (RAM), không ghi đĩa.

📤 Danh sách ngõ ra (Q)

Định nghĩa các nút điều khiển trong tab Ngõ ra.

📥 Danh sách ngõ vào (I)

🚩 Danh sách cờ nhớ (M)

🔢 Danh sách biến số (V)

Type: bit, byte, word (16-bit), dword (32-bit).

❓ Cấu hình LOGO! 230RCE 0BA8

  1. Mở LOGO! Soft Comfort → Tools → Transfer → Configure web server.
  2. Bật Enable web server, đặt user name + password (mặc định admin).
  3. Cấp quyền đọc/ghi (Allow access) cho các vùng nhớ I, Q, M, V cần dùng.
  4. Tải file plc.html này vào SD card qua mục User-defined web pages, hoặc đặt PLC + máy tính cùng LAN rồi truy cập trực tiếp.
  5. Cập nhật IP PLC, user/pass trong tab ⚙ Cài đặt.
  6. Nhấn 🔌 Test để xác nhận kết nối. Đèn xanh ở topbar = OK.

🔧 Tinh chỉnh giao thức

ℹ️
API webserver của LOGO! 8 không có tài liệu chính thức công khai. Adapter hiện tại dùng POST /AJAX với body dạng plain text. Nếu firmware của bạn dùng định dạng khác, sửa hàm plcAdapter.request() trong mã nguồn (gần đầu thẻ <script>).
